GitLab MCP Server

Generate an MCP client configuration. Works against GitLab and Heptapod (Mercurial fork).

Template Config

{
  "mcpServers": {
    "gitlab": {
      "command": "uvx",
      "args": ["--refresh", "--extra-index-url", "https://nikitatsym.github.io/gitlab-mcp/simple", "gitlab-mcp"],
      "env": {
        "GITLAB_URL": "YOUR_GITLAB_URL",
        "GITLAB_TOKEN": "YOUR_ACCESS_TOKEN"
      }
    }
  }
}

Generate Your Config

Base URL of your instance. The server will auto-detect whether it's GitLab or Heptapod.

Personal access token, project token, group token, or OAuth2 bearer.

Use gitlab/heptapod to skip the auto-detect probe (saves one round-trip at startup, useful when the probe is blocked by network).

Defaults: GITLAB_TIMEOUT=30.0, MCP_GITLAB_BRIEF_MAX=200 (0 disables note truncation).


  


  

    
How to Create a GitLab Access Token

    
    
      
  1. Log in to your GitLab/Heptapod instance.
    2. 
      
  2. Go to User Settings → Access Tokens.
    3. 
      
  3. Name the token (e.g. mcp-server) and pick an expiration date.
    4. 
      
  4. Select scopes — api for full read/write access, or finer-grained: read_api, read_repository, write_repository.
    5. 
      
  5. Click Create personal access token and copy the value immediately — it’s shown only once.
    6. 
      
  6. Paste the token above, click Generate Config, and put the result into your MCP client.
    7. 
    

    
Project- or group-scoped operations? Use a project access token from project Settings → Access Tokens instead.

  


  

    
Heptapod Notes

    
    
      
  1. The server detects Heptapod automatically by probing /api/v4/projects/vcs_type_stats.
    2. 
      
  2. On Heptapod, four hg_* tools become available: hg_get_config, hg_set_config, hg_get_raw_hgrc, hg_create_topic_mr.
    3. 
      
  3. Mercurial branches/topics appear in API responses as branch/<name> and topic/<target>/<name>. The server preserves them verbatim — pass them as-is when constructing refs.
    4. 
      
  4. Forks of Mercurial projects are blocked by Heptapod itself; the server raises a clean error before hitting the network.
    5. 
      
  5. Personal forks, public projects, and merge commits work normally on Git projects hosted on Heptapod.
    6. 
    

  


  

    
Where to Put the Config

    
    
      
  1. Claude Desktop — paste into claude_desktop_config.json.
    2. 
      
  2. Cursor — paste into .cursor/mcp.json in your project root.
    3. 
      
  3. Claude Code — paste into .claude/settings.json or run claude mcp add. Global config: ~/.claude.json → "mcpServers".
    4. 
      
  4. For other MCP clients, consult their docs on where the server config lives.
    5.
